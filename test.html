YouTube History Quick Delete 확장 프로그램

📦 설치 방법

1단계: Chrome 브라우저에서 chrome://extensions/ 접속
2단계: 우측 상단의 "개발자 모드" 토글 활성화
3단계: "압축해제된 확장 프로그램을 로드합니다" 클릭
4단계: 이 폴더(DelHist) 선택

🧪 테스트 시나리오

기본 테스트: YouTube 시청 기록 페이지로 이동하여 삭제 버튼이 각 영상에 표시되는지 확인
삭제 테스트: 빨간 삭제 버튼을 클릭하여 자동으로 메뉴가 열리고 삭제가 실행되는지 확인
무한 스크롤 테스트: 페이지를 아래로 스크롤하여 새로 로드되는 영상에도 삭제 버튼이 자동으로 추가되는지 확인
테마 테스트: YouTube 다크/라이트 테마에서 삭제 버튼이 잘 보이는지 확인

🔧 개발자 도구 확인

F12를 눌러 개발자 도구를 열고 Console 탭에서 다음 로그들을 확인하세요:

DelHist: 초기화 시작
DelHist: 15개 아이템 스캔 완료
DelHist: 초기화 완료

⚠️ 문제 해결

  • 삭제 버튼이 보이지 않음: 페이지를 새로고침하거나 확장 프로그램을 다시 로드
  • 삭제가 실패함: 잠시 후 다시 시도하거나 다른 영상으로 테스트
  • 메뉴가 열리지 않음: YouTube 페이지가 완전히 로드될 때까지 기다림

🎯 주요 기능

  • ✅ 시청 기록 페이지에서만 작동
  • ✅ 일반 영상과 쇼츠 모두 지원
  • ✅ 무한 스크롤로 로드되는 새 항목에도 자동 적용
  • ✅ 다크/라이트 테마 모두 지원
  • ✅ 키보드 접근성 지원
  • ✅ 한국어/영어 메뉴 자동 감지
