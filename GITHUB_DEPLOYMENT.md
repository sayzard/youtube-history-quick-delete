# GitHub 배포 명령어

## GitHub에서 리포지토리 생성 후 실행할 명령어들:

# 1. 원격 저장소 추가 (리포지토리 이름에 맞게 수정)
git remote add origin https://github.com/YOUR_USERNAME/youtube-history-quick-delete.git

# 2. 기본 브랜치를 main으로 설정
git branch -M main

# 3. 첫 번째 푸시
git push -u origin main

## 리포지토리 이름 제안:
- youtube-history-quick-delete
- youtube-watch-history-deleter  
- youtube-history-cleaner
- quick-delete-youtube-history

## 리포지토리 설명 제안:
"Chrome extension to quickly delete YouTube watch history items with one click. Supports videos, shorts, and infinite scroll."
